## Mapping Food Systems end-to-end

Before Project Eleven, I led a foundational research initiative to map HelloFresh's Food Systems processes from end to end — specifically in the context of migrating the US market to international tooling. This wasn't a small exercise. It meant getting deep into a highly fragmented operational landscape across multiple markets and user types.

That work gave Project Eleven its backbone. The complexity of the pipeline — and the case for unifying it — wasn't hypothetical. It was already documented.

<StatGrid v1="53" l1="Stakeholders interviewed across Tech and Ops" v2="6" l2="User groups across US, CA, UK, DACH — Recipe Developers, Editors, PMs, Menu Planners, Demand Planners, Procurement Ops" v3="130" l3="Steps mapped across Food Systems US and International" />

The ask arrived with almost no structure: imagine what it could look like if HelloFresh could take a recipe from creation to the weekly menu in one week — and show us something real, fast. One whiteboard diagram, no workflows mapped, no existing UI, no spec.

Just a business need and a deadline.

Seven separate internal tools handled pieces of this process. No one had ever tried to stitch them together into a single coherent experience. I had two weeks to understand the need, define the solution, and prototype it well enough to put in front of C-level leadership.

> Decisions that would normally take weeks had to happen in hours. There was no time to wait for clarity — I had to manufacture it.

## Structure first, then speed

The first thing I did was build a map. Before touching any tools, I ran a rapid discovery phase: whiteboard flow charts, a workflow map, and a feature set — all defined in week one. This was itself iterative — each phase of the pipeline was owned by a different PM, so getting the user goals, JTBDs, and data flows right required 1–2 check-ins with the full group. Only once that foundation was solid could I move fast without thrashing.

<FullImage src="/images/project-eleven-workflow-map.jpg" alt="Workflow map — four-stage pipeline from Validate to Inspire, Create, and Activate" contained />

Then I used AI to compress every phase that followed.

**Week 1 — Define**

Generated JTBDs, actions, tools, and a feature set using AI prompting. Built a workflow map covering the full pipeline from consumer favorites to menu activation. Total: 372 prompts across the sprint.

**Week 2 — Design**

Prompted Magic Patterns with the workflow map and predefined user actions. Iterated directly from Figma screenshots. Ran 5 prototype versions incorporating live feedback. No handoff process — design and prototype happened simultaneously.

**Now — Iterate**

Leadership feedback turned around in hours into a new prototype version using v0. The cycle from feedback to working UI collapsed from weeks to a single session.

## Four stages, one unified system

The core of the prototype was a four-stage pipeline that replaced the seven disconnected tools.

**Inspire** — Consumer favorites drive recipe discovery via similarity modeling

**Validate** — Automated constraint checks: allergens, SKU, pricing, compliance

**Create** — GenAI content generation for instructions, imagery, tags, and localization

**Activate** — One-click menu addition with approval flow and Recipe Pool integration

## Vibe coding as a design method

This project wasn't built with traditional prototyping tools. It was built by prompting — using AI agents to generate, iterate, and refine UI at a speed that no conventional workflow could match.

The key insight: AI tools don't just accelerate production — they change what's possible in a given timeframe. Prompting from JTBDs and workflow maps directly into a working UI removes the translation layer between thinking and making.

## Something real, in two weeks

**5** prototype iterations shipped in two weeks

**7→1** legacy tools unified into a single UI

**372** AI prompts across the full sprint

The prototype was used to communicate product vision to C-level leadership and enabled alignment across tech, product, and design — all under an intense timeline that would have made a traditional approach impossible.
